# Stage 1 — Test checklist

این چک‌لیست برای تأیید مرحله اول است. هیچ موردی تا زمان اجرای واقعی و ثبت نتیجه، «قبول‌شده» محسوب نمی‌شود.

## بررسی در Godot Editor
- [ ] پروژه بدون خطای import باز می‌شود.
- [ ] صحنه `res://scenes/main.tscn` به‌عنوان صحنه شروع اجرا می‌شود.
- [ ] اسکریپت‌های GDScript بدون خطای parse بارگذاری می‌شوند.
- [ ] خیابان، پیاده‌روها، ساختمان‌ها، چراغ‌ها و درخت‌ها دیده می‌شوند.
- [ ] بازیکن روی سطح خیابان قرار می‌گیرد و از زمین سقوط نمی‌کند.

## کنترل دسکتاپ برای بررسی سریع
- [ ] کلیدهای WASD بازیکن را حرکت می‌دهند.
- [ ] نگه‌داشتن دکمه راست ماوس و کشیدن آن، دوربین را می‌چرخاند.
- [ ] بازیکن هنگام حرکت در جهت درست می‌چرخد.
- [ ] برخورد بازیکن با ساختمان‌ها و موانع کار می‌کند.

## کنترل لمسی Android
- [ ] جوی‌استیک پایین-چپ نمایش داده می‌شود.
- [ ] کشیدن جوی‌استیک، بازیکن را حرکت می‌دهد.
- [ ] لمس و کشیدن سمت راست صفحه، دوربین را می‌چرخاند.
- [ ] جوی‌استیک و دوربین هم‌زمان ورودی یکدیگر را مختل نمی‌کنند.
- [ ] متن فارسی و چینش HUD در اندازه‌های مختلف صفحه خوانا است.

## عملکرد و پایداری
- [ ] صحنه حداقل چند دقیقه بدون خطا اجرا می‌شود.
- [ ] نرخ فریم روی گوشی هدف قابل‌قبول است.
- [ ] کنترل‌ها در نسبت تصویرهای مختلف افقی از صفحه بیرون نمی‌زنند.

## نتیجه فعلی
فایل‌های پروژه در GitHub ثبت شده‌اند، اما این چک‌لیست هنوز روی Godot Editor یا دستگاه Android اجرا نشده است. وضعیت همه موارد بالا فعلاً «تأییدنشده» است.
