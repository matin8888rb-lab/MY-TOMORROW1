# چک‌لیست پذیرش مرحله ۳ — خانه و زندگی روزمره

## قابلیت‌های افزوده‌شده در کد
- [x] ساخت آپارتمان اجاره‌ای ساده در محدوده شهر
- [x] فضای داخلی اولیه با تخت، میز، یخچال و مبل
- [x] ورود و خروج از خانه با دکمه رابط کاربری
- [x] ساعت و روز پویا با گذر زمان بازی
- [x] کاهش تدریجی گرسنگی و انرژی
- [x] غذا خوردن برای بازیابی گرسنگی
- [x] خواب هشت‌ساعته برای بازیابی انرژی
- [x] ذخیره و بازیابی روز، ساعت، نیازها و شمارش معکوس اجاره

## آزمون‌های لازم در Godot و Android
- [ ] اجرای پروژه بدون خطای GDScript
- [ ] بررسی برخورد دیوارها و ورود/خروج از درگاه
- [ ] بررسی خوانایی پنل و دکمه‌ها در صفحه افقی گوشی
- [ ] بررسی افزایش/کاهش نیازها و گذر ساعت
- [ ] بررسی خواب در ساعت‌های مختلف و عبور روز
- [ ] بستن و اجرای مجدد بازی و بررسی ماندگاری وضعیت
- [ ] بررسی عملکرد روی دستگاه Android

## محدودیت فعلی
اجاره فعلاً به شکل شمارش معکوس هفت‌روزه نمایش داده می‌شود؛ پرداخت پول و خرید غذا به مرحله ۴ (اقتصاد) وابسته است. فایل‌های این مرحله در مخزن ثبت می‌شوند، اما تا اجرای واقعی در Godot و Android، تأیید فنی نشده‌اند.
